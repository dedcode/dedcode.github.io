Computing Pearson correlation

r = Σᵢ (xᵢ − x̄)(yᵢ − ȳ) / √[Σᵢ (xᵢ − x̄)² · Σᵢ (yᵢ − ȳ)²]
For standardized values: r = Σᵢ zₓᵢ zᵧᵢ / (n − 1)

The sums run over all n observations; x̄ and ȳ are the sample means. Same-sign deviations contribute positively; opposite-sign deviations contribute negatively. Correlation measures linear association.

Standardization: three machine-learning features

Mean: x̄ = (Σᵢ xᵢ) / n
Sample standard deviation: sₓ = √[Σᵢ (xᵢ − x̄)² / (n − 1)]
Standardized value: zᵢ = (xᵢ − x̄) / sₓ

Apply this separately to each feature: subtract its mean, then divide by its standard deviation. The result has mean 0 and sample standard deviation 1; its shape and ordering stay the same. This demo uses n − 1; some ML libraries use n for variance.
