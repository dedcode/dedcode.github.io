Where does the kernel trick fit in?

These demos make a nonlinear feature transformation visible. A kernel lets an algorithm calculate dot products in a feature space without explicitly constructing the transformed vectors.

For the squared line, φ(x) = x² and k(x, z) = (xz)². The hill uses the illustrative height h(x₁, x₂) = 3.2 exp[−0.7(x₁² + x₂²)] and a plane at h = 1.024. This three-dimensional picture is not the complete, infinite-dimensional feature space of a Gaussian RBF kernel.
